# Day 5 — Golden run, source walk, repeat and public demonstration

**Budget: 7 task hours + 1 hour buffer.** All checkboxes start unchecked. Complete them only when the work is actually performed.

## A — Golden captured run (2h)

- [ ] 0-30m: start from the documented stopped state, assign run ID and start relevant captures.
- [ ] 30-75m: perform startup, UE/session establishment and the same controlled traffic.
- [ ] 75-105m: stop captures cleanly and check interfaces, timestamps and useful packet content.
- [ ] 105-120m: index artifacts locally and prepare reviewed public excerpts.

## B — Timeline and source explanation (2h)

- [ ] 0-75m: fill all eight D12 timeline rows using observed/inferred/unavailable labels.
- [ ] 75-105m: locate one relevant source handler/state transition at a pinned commit.
- [ ] 105-120m: fill D13, distinguishing source interpretation from runtime proof.

## C — Controlled repeat (2h)

- [ ] 0-30m: stop cleanly and record starting state; use a new run ID.
- [ ] 30-75m: repeat the same procedure and traffic probe.
- [ ] 75-105m: compare outcomes and explain permitted identifier/timestamp differences; preserve any failure.
- [ ] 105-120m: complete D14 with the reproduction sequence and exact repeat outcome.

## D — Demonstration and review (1h)

- [ ] 0-15m: prepare five-minute topology-to-evidence demonstration.
- [ ] 15-30m: present to a peer if available or record locally; label recorded output honestly.
- [ ] 30-45m: complete D15 learning summary and final outcome.
- [ ] 45-60m: update progress, inspect the showcase and publish the supported results.

## E — Review and buffer (1h)

- [ ] Use remaining time for the earliest blocked prerequisite; do not add features.
- [ ] Record hours, observed learning, unresolved question and next action in the daily journal.
- [ ] Review evidence for sensitive data, update progress and publish a small truthful commit.

If the gate fails, mark the relevant item blocked/in progress and state why. Do not check the issue complete just because the day ended.
